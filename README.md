# Alphabet

Каркас для челленджа по кириллическим буквам. Статический сайт без сборки.

## Структура

- `index.html` — страница алфавита и модальное окно буквы.
- `styles.css` — общая визуальная система и responsive layout.
- `app.js` — реестр букв, состояния карточек и маршрутизация `?letter=`.
- `letters/a.js` — изолированный интерактивный модуль для буквы А.

## Как добавить букву

1. Создать `letters/<letter>.js` с экспортом `mount<Letter>(workspace)`.
2. Подключить модуль в `app.js`.
3. Добавить букву в `READY` с номером, статусом, описанием и `mount`.
4. Вернуть из mount-функции cleanup-функцию, если модуль создает обработчики или animation frame.

Карточки будущих букв уже присутствуют в сетке и отключены до добавления модуля.
