# Alphabet

Челлендж по кириллическим буквам: одна буква в день, каждая — интерактивный скетч на canvas. Статический сайт без сборки.

## Структура

- `index.html` — страница алфавита и модальное окно-сцена.
- `styles.css` — монохромная визуальная система и responsive layout.
- `app.js` — список букв, реестр готовых модулей, сетка и маршрутизация `?letter=`.
- `letters/a.js` — модуль буквы А: свет, тень и преграды.
- `letters/b.js` — модуль буквы Б: тела падают в ящик и складываются в букву.
- `letters/v.js` — модуль буквы В: резинка стягивается на окружностях.
- `vendor/matter.min.js` — физический движок, грузится только когда открыта буква, которой он нужен.
- `lab/b.html`, `lab/v.html` — полигоны механик для Б и В, со страницы алфавита не залинкованы.

## Как добавить букву

1. Создать `letters/<letter>.js` с экспортом `mount<Letter>(workspace)`.
2. Подключить модуль в `app.js` и добавить букву в `READY`.
3. Вернуть из mount-функции cleanup: он должен снять слушатели и удалить всё, что модуль добавил в `workspace`.

Модуль владеет своим слоем: собственные подписи, панели и подсказки помечает атрибутом `data-letter-layer` и рисует внутри `#letter-canvas`. Номер буквы и статус карточки выводятся автоматически.
