# Claude Code

Перед работой обязательно прочитай `AGENTS.md` и следуй его инструкциям.

## Не забывать

`AGENTS.md` читается один раз в начале и к концу длинной сессии тускнеет,
а этот файл подкладывается заново. Поэтому здесь — то, от чего отклоняюсь
первым делом. Подробности всё равно в `AGENTS.md`.

- Цвет в полигоне — только из констант каркаса (`INK`, `ink(a)` и прочие).
  Написанная руками `rgba(22,22,22,…)` не переключится вместе с фоном.
- Полигон — стенд. Версий против кэша в нём нет: стаб и `lab.js` ставят
  метку времени сами. Ручной `?v=` не заводить.
- Открытая по форме задача — сначала 2–3 варианта, потом код.
- Перед «готово» пройти список из раздела «Готово, когда» в `AGENTS.md`.
- Холст Я ведут два файла в `docs/superpowers/specs/`: спека держит решения,
  план — состояние. Свой третий файл не заводить, дописывать в эти.
