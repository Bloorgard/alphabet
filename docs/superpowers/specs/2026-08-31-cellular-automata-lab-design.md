# Лаборатория клеточных автоматов — дизайн

Дата: 2026-08-31

## Зачем

Идея буквы О началась с образа «камешек в пруд»: пользователь ставит точку на
чистом холсте, из неё расходятся узоры. Чтобы не просить готовое решение
вслепую, а разобраться в клеточных автоматах и научиться крутить их правила
руками, механика выносится в отдельную учебную лабораторию — не в систему
букв. Когда какой-то результат зацепит, он аккуратно переносится в
`lab/o-lab.js` как ещё одна механика буквы О (режим `MODES`, по контракту
`AGENTS.md`).

Referenced материалы пользователя:
- Wolfram NKS, «cellular automata that approach circular shape»
  (wolframscience.com/nks/p174).
- cell-auto.com/dimensions — автоматы, замкнутые в кольцо.
- fourmilab.ch/cellab/classic — исторический CeLLab, включая эффектную
  графику (Maxine Headroom by RC Rug).

## Расположение

Новая папка в корне репозитория, вне `lab/` и вне системы букв:

```
automata/
  index.html
  automata.js
  automata.css   (при необходимости; можно обойтись стилями в html)
```

Публикуется вместе с сайтом (как и `lab/`), никуда не залинкована с главной
страницы — доступна по прямому адресу `/automata/`. Не подчиняется контракту
`lab/<буква>.html` (`lab.js`/`lab.css`, панель по Tab, цвет только из
констант каркаса) — это отдельный инструмент, не полигон буквы.

## Область первой версии

Одна семья автоматов: двумерные тоталистические (Life-like), B/S-нотация
(рождение/выживание по числу живых соседей). Окрестность — Мур или фон
Нейман, переключается. Это прямое попадание в образ «камешек в пруд»: один
живой пиксель + правило → узор, расходящийся во все стороны.

Не входит в первую версию (осознанно, roadmap ниже): одномерные автоматы
Вольфрама, кольцевая/полярная сетка, много-состояние / Larger-than-Life.

## Архитектура

Три независимые части, чтобы позже можно было заменить сетку или добавить
семью правил, не переписывая остальное:

**Сетка** — абстракция «клетка → соседи», не завязанная на голый
`x/y`-массив в остальном коде. Первая реализация — прямоугольная, с
переключателем границы: обрезать (клетки за краем не считаются) или завернуть
в тор (`(x + size) % size`). Кольцевая/полярная реализация подключается
позже как вторая сетка за тем же интерфейсом.

**Правило** — B/S как две битовые маски (какие числа соседей рождают
мёртвую клетку, какие оставляют живую живой). Переключатель окрестности
(Мур — 8 соседей, фон Нейман — 4) хранится рядом с правилом, а не в сетке:
семья остаётся 2D-тоталистической, меняется только то, что считается
соседом.

**Рендер** — canvas, клетка = закрашенный квадрат, шаг без анимации
перехода (сырой кадр понятнее для разбора, чем сглаженная интерполяция).

## Взаимодействие

Чистый холст. Клик ставит одну живую клетку — точку входа. С этого момента
автомат живёт по текущему правилу, шаг за шагом.

Управление (панель открыта всегда, не прячется по Tab — здесь она и есть
суть страницы):
- пауза / шаг вперёд / скорость;
- «заново» — очистить холст, ждать новый клик;
- переключатель границы (обрезать / завернуть в тор);
- переключатель окрестности (Мур / фон Нейман);
- редактор правила: чекбоксы 0–8 для рождения, 0–8 для выживания
  (в духе нотации Golly, B3/S23 и т.п.);
- «случайное правило» — заполняет чекбоксы случайно;
- размер сетки.

## Про разнообразие узоров

Одно и то же правило + одна и та же точка старта на сетке без завёрнутых
краёв всегда дают один и тот же узор. Это не ограничение, которое нужно
обходить, а суть автомата: он детерминирован. Разнообразие достигается сменой
правила, а не рандомом внутри шага — одна изменённая цифра в B/S уводит
поведение от мгновенной смерти до заливки всего экрана. Кнопка «случайное
правило» и есть генератор разнообразия для первой версии.

Отдельно от этого пользователь предложил в разговоре более сложные способы
удержать вариативность при фиксированном правиле: привязывать под-правила к
координатам (разные зоны сетки живут по разным B/S), скрытые условия
(правило меняется по внешнему счётчику/условию, не видимому на холсте),
преграды (клетки, которые не участвуют в подсчёте соседей и ломают
симметрию роста). Это не входит в первую версию — зафиксировано как заметки
на будущее, если базовый B/S-редактор покажется слишком предсказуемым.

## Цвет

Правило «цвет только из констант каркаса» (`INK`, `PAPER`,…) действует для
`lab/<буква>` — здесь не применяется, страница не часть этого контракта.
Простая рабочая палитра: живая клетка / мёртвая клетка / клетка-камешек
(точка входа) отдельным оттенком, чтобы видеть фронт рождения отдельно от
устоявшегося узора. Выбор конкретных цветов — на этапе реализации, не
принципиален для дизайна.

## Дальше (не в этой итерации)

- Кольцевая/полярная сетка (соседство по кругу и по радиусу) — прямой мостик
  обратно к форме буквы О.
- Одномерные автоматы Вольфрама (elementary CA, правило как функция тройки
  соседей, время — вниз по холсту).
- Много-состояние / непрерывные автоматы (Larger than Life, реакция-диффузия,
  циклические автоматы) — самая эффектная графика, самая сложная модель.

Когда один из результатов лаборатории зацепит для буквы О — переносится
отдельным режимом в `MODES` в `lab/o-lab.js`, по контракту `AGENTS.md`.
